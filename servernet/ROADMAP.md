# وضعیت و ادامهٔ توسعه

| خروجی | وضعیت |
| --- | --- |
| fork و دریافت موتور | انجام شد؛ upstream اصلی حفظ است |
| چت متنی Gateway و connector داخلی | پیاده‌سازی و تست ساختگی موفق |
| نسخه مشتری اختصاصی ServerNet، fa/en/tr و IRANSans | کد و build آماده؛ مشاهدهٔ مرورگر/موبایل در محیط نصب هنوز لازم است |
| ورود با حساب کنسول/گوگل و ثبت‌نام فعلی، کلید محدود خودکار و موجودی مشترک | دو طرف پیاده‌سازی شده؛ سمت Laravel در PR323، پیش‌فرض خاموش |
| ثبت نسخه مشتری در GitHub | دسترسی نوشتن در ادامهٔ نشست باز شد؛ انتشار develop و ساخت native در حال انجام است |
| محیط خصوصی و پذیرش مالی واقعی | انجام نشده؛ پس از تنظیم دو طرف و سقف آزمایش |
| رسانهٔ Gateway | مرحلهٔ بعد؛ native endpoint و بازیابی وضعیت بدون خرید تکراری |
| آموزش مدل روی GPU | مرحلهٔ بعد؛ worker جدا، دیتاست خصوصی و حسابداری زمان اجرا |
| کلاینت مستقل Desktop با نام ServerNet | ZIP آزمایشی مک Intel/Apple Silicon و ویندوز x64 ساخته شد؛ نصب‌کننده Windows NSIS و Mac DMG امضاشده و تست نصب واقعی باقی است |
