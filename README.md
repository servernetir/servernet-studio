# ServerNet Studio

فضای کار هوش مصنوعی سرورنت، با همان حساب کنسول، ورود گوگل و کیف پول مشترک.

- نسخهٔ وب فارسی با IRANSans، انگلیسی و ترکی.
- کلاینت مستقل ویندوز و مک؛ ورود و ثبت‌نام از همان مسیر مرکزی سرورنت.
- مدل‌های آنلاین AI Gateway، تاریخچهٔ جدا برای هر مشتری و محاسبهٔ هزینه در هستهٔ سرورنت.

## وضعیت نسخهٔ 0.2.0

کد در develop منتشر شده است. نصب‌کنندهٔ آزمایشی ویندوز و اجرای اولیه روی Windows در CI موفق‌اند. ZIPهای آزمایشی مک Intel/Apple Silicon ساخته شده‌اند؛ اجرای native مک هنوز تأیید نشده است. این فایل‌ها نسخهٔ عمومی امضاشده نیستند.

قابلیت فعلی چت متنی آنلاین است. آموزش مدل، رسانه و ابزارهای محلی در این نسخهٔ مشتری عرضه نشده‌اند. نصب تولید، امضای دیجیتال/notarization و پذیرش واقعی حساب/صورتحساب باقی‌اند.
